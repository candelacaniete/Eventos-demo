# La Barca Eventos — Demo Visual

Demo frontend premium para **La Barca Eventos**, salón de eventos en Pilar, Buenos Aires.

Sitio no funcional pensado para presentación comercial: experiencia visual, fotografía y flujo de consulta de disponibilidad.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS v4

## Cómo ejecutar

```bash
npm install
npm run dev
```

Build de producción:

```bash
npm run build
npm run preview
```

## Notas

- Formularios y CTAs son visuales (sin backend).
- Las fotografías son placeholders de alta calidad para la demo.
